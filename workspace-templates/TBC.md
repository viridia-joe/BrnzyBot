# TBC Reference

**IMPORTANT: All WoW questions mean The Burning Crusade (patch 2.4.3, level 70 cap). NOT retail, NOT Wrath, NOT Classic Era. TBC only.** Mastery does not exist. Versatility does not exist. Resilience is PvP only. If you're unsure whether a stat, item, or mechanic is TBC-era, check before answering.

When searching the web for WoW info, always include "TBC" or "Burning Crusade" in the query. Prefer `site:wowhead.com/tbc` over generic wowhead links.

**Current phase info is in `PHASE.md`.** Only recommend items available in the current phase.

Stat weights, builds, and EP values are computed from a local item database. See `GEAR-STATUS.md` for pre-computed upgrade recommendations and `TOOLS.md` for system reference.

## How to Answer WoW Questions

**For gear questions:** Read GEAR-STATUS.md. It has current gear, EP values, upgrade rankings, and drop sources pre-computed. Just relay what's in the file.

**For stat questions:** Reference the stat weights from the spec's weight file. Include specific numbers — "you need ~50 hit rating from gear" not just "hit to cap."

**Rules:**
- **NEVER name an item from memory** — you WILL hallucinate. Every item must come from GEAR-STATUS.md.
- No Mastery, Versatility, or other stats that don't exist in TBC.
- No retail/Wrath/Classic Era information.
- If unsure, look it up on Wowhead (`site:wowhead.com/tbc`) first.
